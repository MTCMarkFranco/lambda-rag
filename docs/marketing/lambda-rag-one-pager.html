How Projection Rules Work — A Real Example

Plain-language policy becomes a testable, repeatable rule applied over any document paragraph.

① The Policy Says

"Undisputed invoices shall be payable within thirty (30) days of receipt of a valid invoice."

— Treasury Board Directive on Payments

② AI Drafts → Human Approves → Rule

Natural language description:

"Payment terms must be net 30 days or fewer from receipt of an undisputed invoice."

Selector (which paragraphs to check):

category == "payment_terms"

Lambda expression (the test):

text.Contains("30 days") || text.Contains("net 30") || text.Contains("15 days")

③ Contract Paragraph Under Review

"5.2 Payment. Customer shall remit payment within net 30 calendar days following receipt of Vendor's undisputed invoice."

✓ PASS

④ A Different Contract…

"5.2 Payment. All amounts shall be due net 60 days from date of invoice."

✗ FAIL — Remediation provided

→ "Replace with: Customer shall pay all undisputed invoices within thirty (30) days."

Key Concepts — The Novel Pattern

How prose becomes enforceable code.

Projection Rule
A machine-testable rule derived from a regulation or policy. Contains a selector (what to look at), a lambda (what to check), and a citation (where this requirement comes from). Authored with AI help, enforced without it.
Lambda Expression
A small, deterministic test — like a formula in a spreadsheet — that returns true or false. "Does this paragraph mention 30 days?" is a lambda. It runs the same way, with the same result, every time.
Topic Map Projection
The step that turns unstructured paragraphs into categorized buckets (e.g., "this paragraph is about payment terms"). Uses a fixed dictionary — not AI — so the same document always maps the same way.
Signed Ruleset
The locked, fingerprinted bundle of all rules for a domain. Once signed, it cannot drift. If the fingerprint matches, the verdict is reproducible — guaranteed by the system, provable by the tests.
Gap Verdict
When a rule applies but the document says nothing about it. Other systems either guess or silently pass. Lambda-RAG flags it explicitly — because silence is not the same as compliance.
Golden-Master Tests
35 automated proofs that run on every change, across 5 industries. They guarantee that the engine hasn't drifted — the same inputs still produce the same verdicts, byte for byte.
